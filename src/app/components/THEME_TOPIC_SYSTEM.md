# Theme and Topic Management System

## Overview

The system implements a two-level hierarchy for content organization:

1. **Level 1 - Themes (Project Level)**: Broad, reusable categories
2. **Level 2 - Topics (Item Level)**: Specific, granular subjects for individual content

## Architecture

```
Project
  └── Themes (Level 1)
       ├── "Work Stress"
       ├── "Anxiety"
       └── "Company Culture"
            └── Content Items (Level 2)
                 ├── Topic: "Breathing Techniques for Work Stress"
                 ├── Topic: "Team Building Activities"
                 └── Topic: "Managing Remote Teams"
```

## Level 1: Themes (Project Level)

### Location
Project Settings → Themes Section

### Features

**1. Manual Theme Management**
- Add themes manually with name, description, and color
- Edit existing themes
- Delete themes (with warning if used by content)
- Each theme has:
  - Name (required)
  - Description (optional)
  - Color tag
  - Usage count

**2. Add from Source**
- Paste any URL (Instagram profile, blog article, social media post, website)
- AI analyzes the content and suggests relevant themes
- Each suggestion includes:
  - Theme name
  - Description
  - Confidence score
  - Select/deselect checkbox
- User reviews and approves before adding

**3. Theme Display**
- List view with color-coded tags
- Shows usage count for each theme
- Hover actions for edit/delete
- Color picker with preset palette

### Usage in Code

```tsx
import { ThemesManager } from './components/themes-manager';

// In project settings
<ThemesManager />
```

### Component Props
The `ThemesManager` component is self-contained and manages its own state.

## Level 2: Topics (Item Level)

### Location
Individual content creation/edit screens

### Features

**1. Content Format Detection**
- **Long-form** (blog posts, articles): Shows Topic + Title fields
- **Short-form** (social posts, tweets): Shows only Topic field

**2. Topic Field**
- Auto-generated for new content items
- Fully editable by user
- Shows "Auto-generated and fully editable" hint
- Specific to the individual piece of content

**3. Title Field (Long-form only)**
- Separate from topic
- Used as the specific headline
- Example: 
  - Topic: "Breathing Techniques for Work Stress"
  - Title: "5 Simple Breathing Exercises to Reduce Workplace Anxiety"

**4. Topic Change Notification**
When user edits a topic:
- Yellow notification bar appears
- Message: "Topic updated — regenerate content to apply changes"
- Actions: "Regenerate" button or "Dismiss" (X)
- Auto-triggers regeneration workflow if user clicks "Regenerate"

### Usage in Code

```tsx
import { TopicTitleFields } from './components/topic-title-fields';

// Long-form content
<TopicTitleFields
  format="long-form"
  topic="Breathing Techniques for Work Stress"
  title="5 Simple Breathing Exercises to Reduce Workplace Anxiety"
  onTopicChange={(topic) => setTopic(topic)}
  onTitleChange={(title) => setTitle(title)}
  onRegenerateRequest={() => regenerateContent()}
  autoGeneratedTopic="Breathing Techniques for Work Stress"
/>

// Short-form content
<TopicTitleFields
  format="short-form"
  topic="Quick Desk Meditation"
  onTopicChange={(topic) => setTopic(topic)}
  onRegenerateRequest={() => regenerateContent()}
  autoGeneratedTopic="Quick Desk Meditation"
/>
```

### Component Props

```tsx
interface TopicTitleFieldsProps {
  format: 'long-form' | 'short-form';
  topic: string;
  title?: string;
  onTopicChange: (topic: string) => void;
  onTitleChange?: (title: string) => void;
  onRegenerateRequest?: () => void;
  autoGeneratedTopic?: string;
}
```

## Workflow Examples

### Example 1: Adding Themes from Instagram Profile

1. User clicks "Add from Source" in Themes section
2. Pastes Instagram URL: `https://instagram.com/mindfulness_daily`
3. System analyzes profile and suggests:
   - Mental Wellness (95% match)
   - Mindfulness (88% match)
   - Meditation (82% match)
   - Self-Care (76% match)
   - Work-Life Balance (71% match)
4. User selects first 3, clicks "Add 3 Themes"
5. Themes added to project with auto-assigned colors

### Example 2: Creating Content with Topic

1. User creates new blog post (long-form)
2. Selects theme "Work Stress"
3. System auto-generates topic: "Breathing Techniques for Work Stress"
4. System auto-generates title: "5 Simple Breathing Exercises to Reduce Workplace Anxiety"
5. User can edit both topic and title
6. If topic is edited, notification appears prompting regeneration

## Best Practices

1. **Themes are broad**: Use themes for high-level categorization
   - Good: "Work Stress", "Team Building", "Mental Wellness"
   - Avoid: "5 Tips for Managing Stress" (too specific)

2. **Topics are specific**: Use topics for individual content subjects
   - Good: "Breathing Techniques for Work Stress"
   - Avoid: "Stress" (too broad)

3. **Title vs Topic**:
   - Topic: The subject matter (what it's about)
   - Title: The marketing headline (how to present it)

4. **Add from Source**: Use for discovering themes from existing content
   - Works best with content-rich sources
   - Review suggestions before adding
   - Edit descriptions to match your project

5. **Topic Regeneration**: Always regenerate content after changing topics
   - Topics influence AI content generation
   - Changes won't apply until regeneration
